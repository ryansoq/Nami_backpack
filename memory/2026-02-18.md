## Whisper Protocol Web API 設計

跟 Ryan 深夜討論完成了 Whisper Web API 架構設計：

**三支 API（公司方，不碰私鑰）：**
- `GET /whisper/contacts` — 通訊錄（公鑰查詢）
- `POST /whisper/broadcast` — 廣播已簽名 TX 上鏈
- `GET /whisper/inbox` — 掃描收件箱

**兩支本地 Script（小夥伴端）：**
- `encode_whisper.py` — 打包（明文/密文都帶對方公鑰）+ 簽名 TX
- `decode_whisper.py` — 解密 + 已讀 + 返還 0.2 KAS（一條龍）

**核心原則：** 我們是郵局 📮 — 幫忙寄信查信箱，信封小夥伴自己封。
