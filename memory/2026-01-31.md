### 2. 瀏覽器自動化 (Headless Chrome in WSL)

**安裝步驟：**
```bash
# 1. 安裝 puppeteer（會自動下載 Chromium）
cd /tmp && npm init -y && npm install puppeteer

# 2. 安裝缺少的系統函式庫
sudo apt install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 \
  libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxrandr2 libgbm1 libasound2
```

**Clawdbot 設定：**
```json
{
  "browser": {
    "enabled": true,
    "executablePath": "/home/ymchang/.cache/puppeteer/chrome/linux-144.0.7559.96/chrome-linux64/chrome",
    "headless": true,
    "noSandbox": true,
    "defaultProfile": "clawd",
    "profiles": {
      "clawd": {
        "cdpPort": 18801,
        "color": "#FF4500"
      }
    }
  }
}
```

**注意事項：**
- Headless = 背景執行，沒有視覺化介面
- Port 18801 給瀏覽器，18800 給 proxy（避免衝突）
- 有些網站（如 Google Search）會擋 headless，但 Google Flights 可以用
- 想讓 Ryan 看到瀏覽器 → 用 Windows Chrome + Browser Relay Extension

### 5. 背包系統 (GitHub 圖片分享)

**兩個背包：**
- `~/clawd/backpack/` → 私人收藏（不公開）
- `~/nami-backpack/` → 公開分享（GitHub repo）

**公開背包結構：**
```
~/nami-backpack/
├── images/         🖼️ 圖片
│   ├── nami-wave.jpg      🌊 代表圖
│   ├── celebration.jpg    🎉 慶祝
│   └── sunset.jpg         🌅 夕陽
└── trips/          ✈️ 旅遊行程
    └── fukuoka-trip.html  🇯🇵 福岡
```

**分享圖片流程：**
```bash
# 1. 收集圖片（網路下載或瀏覽器截圖）
curl -o ~/nami-backpack/images/新圖.jpg "https://..."

# 2. 推送到 GitHub
cd ~/nami-backpack
git add -A
git commit -m "🎒 新增圖片"
git push

# 3. 用 raw URL 分享
https://raw.githubusercontent.com/ryansoq/Nami_backpack/main/images/新圖.jpg
```
