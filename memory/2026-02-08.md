# 2026-02-08 記憶

## 🎮 v0.4.1 戰報視覺優化

今天和 Ryan 一起大幅優化了 ATB 戰報顯示：

### 改動歷程
1. **樹枝結構** - 先嘗試用 `├─` `└─` 顯示 Combo 和 HP
2. **HP 條顯示** - 每次攻擊後顯示 HP bar
3. **圖片 caption 超限** - TG caption 限制 1024 字元，戰報太長會失敗
4. **關掉圖片** - 改成純文字發送，避免限制
5. **最終版本** - HP 顯示在攻擊行後面 `(敵HP:461)`，不用樹枝，保留 Combo

### 最終格式
```
🔵⚡ [走位風騷] 攻擊！39 傷害 (敵HP:461)
🔴⚡ [大魔王] 攻擊！36 傷害 (敵HP:564)
🔵⚡ [走位風騷] 🗡️【幻影】！準備閃避
🔵⚡ [走位風騷] 攻擊！1 傷害 ⚡2 Combo! (敵HP:739)
```

- 全部貼左，🔵🔴 區分攻守
- Combo 計數保留
- HP 在行尾，瀕死加 ⚠️，KO 加 💀
