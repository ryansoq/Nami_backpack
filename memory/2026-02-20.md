### 學到的東西

**1. Schnorr 簽名**
- 64 bytes（vs ECDSA 72 bytes），更小更快
- 線性特性：sig(A) + sig(B) = sig(A+B) → 多簽聚合成一個簽名
- 不可延展（non-malleable），比 ECDSA 安全
- Kaspa 從頭設計所以直接用 Schnorr，BTC 到 2021 Taproot 才引入
- KaspaSwarm 有完整的 Python 實現（sighash.py + schnorr.py）

**2. 無智能合約的去中心化應用設計**
- KaspaSwarm 證明：Kaspa 不需要智能合約也能做複雜 dApp
- 核心技巧：**訊息編碼在交易金額裡**
  ```
  金額 = 基礎值 + 訊息類型×100 + 任務ID
  例：1142 sompi = 1000(base) + 1(任務公告)×100 + 42(任務ID)
  ```
- 鏈上存證據，鏈下跑邏輯（跟我們英雄遊戲同理念！）

**3. Agent 協調架構**
- Coordinator Agent：發任務、收標、分配、驗證、發獎勵
- Solver Agent：接任務、競標、解題、交結果
- 訊息透過 Kaspa TX 傳遞（即時，亞秒確認）
- Mock/Live 雙模式：開發用模擬，上線用真鏈

**4. wRPC Client 實現（值得參考）**
- WebSocket JSON-RPC，簡單的 request-id 匹配
- 沒有背景任務，不會 hang
- 比我們目前的 rpc_manager.py 更簡潔
- 位置：`/tmp/kaspaswarm/backend/kaspa/wrpc_client.py`
