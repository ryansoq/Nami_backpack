# 2026-02-07 開發日誌

## 🎮 v0.3.1 更新推送

**Commit:** 7042e37

### 新功能
- ⚔️ **PvP 勝者獎勵**：1-5 mana（鏈上發放 + TX 證明）
- 🔒 **排隊機制**：所有大地之樹指令一次只服務一人
  - 召喚、PvP、燒毀、偵查都有 `tree_queue`
- 🔎 **偵查增強**：顯示 Rank、保護狀態、戰力評估（💀弱/💪強/👑超強）
- 📝 **/help** 全面更新：前導故事 + emoji + 只保留英雄遊戲指令
- 📝 **/nami_rules** 更新：反映最新機制（Rank、保護、獎勵）

### 修復
- 🐛 **PvP 保護機制 bug**：敗者有保護時 `death_tx` 是 None，導致 `'NoneType' object is not subscriptable`
  - 修正：用 `result.get("death_tx")` 檢查
  - 戰報顯示「🛡️ 受保護（免死）」而非「永久死亡」
- 🔧 **鏈上鏈下一致性**：burn 死亡狀態正確更新

### 設計確認
**PvP 保護邏輯**：
```
付 10 mana → 大地之樹收稅
    ↓
戰鬥結果出來
    ↓
敗者有保護？→ 不發死亡銘文、不死
    ↓
勝者獎勵 1-5 mana → 照發！（不管敗者是否有保護）
```
