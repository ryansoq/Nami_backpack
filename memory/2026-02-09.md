## 🎮 像素英雄舞台 Canvas 開發

### 版本演進
- **v2**: Canvas 2D 遊戲引擎，英雄會走動、戰鬥、說話
- **v3**: 戰鬥回放系統，讀取 JSON 播放 ATB 戰鬥動畫
- **v4**: 雙區域設計（左 1/3 戰鬥舞台 + 右 2/3 世界之樹）
- **v5**: 使用 Ryan 的像素圖片 + 稀有度光暈效果

### 網址
https://ryansoq.github.io/Nami_backpack/projects/pixel-hero-stage/

### 技術亮點
- HTML5 Canvas + JavaScript（無框架）
- 60fps 動畫迴圈（requestAnimationFrame）
- JSON 輪詢取得最新戰鬥資料
- 稀有度光暈效果（Common 無光 → Mythic 紅光閃爍）

## ⚔️ ATB 戰鬥引擎 v0.5

### 新增功能
- `BattleLog.events[]` — 結構化事件記錄
- `BattleLog.set_tick()` — 設定當前 tick
- `BattleLog.add_event()` — 添加 Canvas 事件

### 事件類型
- `battle_start` / `battle_end`
- `attack` / `skill` / `evade`
- `backstab` / `berserk`
- `death`

### 效果
戰鬥過程 100% 同步到網頁 Canvas！
