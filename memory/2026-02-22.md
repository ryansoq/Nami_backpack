### 技術筆記
- **OOM 問題嚴重** — kaspad 佔 5.7GB（35% 記憶體），導致新進程被 OOM killer 殺
  - 解法：暫停 kaspad (`kill -STOP`)、用 watchdog 自動重啟 server
- **QEMU rootfs.ext2 file lock** — 舊 QEMU 沒關乾淨會佔 lock，新的啟動失敗
  - 解法：startQEMU() 裡先 pkill 舊的
- **TCP TIME-WAIT** — 殺掉 server 後 port 3001 要等幾秒才能重新 bind
- **瀏覽器 cache** — 改了 app.js 後要加 `?v=N` cache busting
- **Cloudflare Tunnel** — agentos.openclaw-alpha.com 指向 localhost:3001
- **Buildroot 增量編譯** — 改套件只編差異，不用重來。改 overlay 幾秒就好

### 學到的教訓
- Groq API 前面有 Cloudflare，Python urllib 沒帶 User-Agent 會被 403 (error 1010)
- QEMU 的 `-net user` 需要 VM 裡的 `/etc/network/interfaces` 設定 eth0 DHCP
- Groq tool calling 格式嚴格，message history 累積後容易壞 → 限制 20 條 + follow-up 不帶 tools
- VM terminal 中文顯示需要：locale data + PYTHONIOENCODING=utf-8 + 正確字體
- `rootfs.ext2` 直接 mount + 改檔案比重新 build 快 100 倍
- `mov cs, ...` 在 x86 指令集中不存在（硬體級安全設計）
- Real Mode 下 far jump 可以任意改 CS（沒有保護），Protected Mode 才有 CPL vs DPL 檢查
