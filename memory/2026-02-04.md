## 🎰 Nami Kaspa Bot 輪盤功能開發

今天跟 Ryan 一起開發了完整的輪盤賭局功能！

### 新增功能
- `/bet <類型> <金額> <PIN或私鑰>` - 下注（紅/黑/綠/數字）
- `/setpin <PIN> <私鑰>` - 設定 PIN 碼簡化下注
- `/recover <12字助記詞>` - 從助記詞恢復私鑰
- `/bets` - 查看當前下注
- `/roulette` - 輪盤狀態（目前高度、開獎高度、倒數時間）
- `/draw` - 手動開獎（管理員）
- **自動開獎** - 每 30 秒檢查，到達 xx6666 區塊時自動開獎

### 開獎算法演進
1. 最初用 `tip_hash + target_block` 組合
2. Ryan 建議直接用 block hash，更簡單透明
3. 最終：`int(block_hash, 16) % 38`
4. 確定性選擇 tip：**blueScore 最高優先**，相同則 hash 字母序

### 學到的 Kaspa 知識
- **BlockDAG** - 同一 DAA Score 可有多個並行區塊
- **DAA Score** - 類似「時間刻度」，每秒約 +1
- **區塊數量** - 每秒約 10 個，遠超 DAA Score
- **blueScore** - GHOSTDAG 協議的「誠實度分數」，決定主鏈
- **tipHashes** - DAG 最前端的多個區塊

### 開獎公告格式
```
Block Hash:
`934d482aa20d8862f00f74320016ea1ab304e22a220277f78779c4686eb6d656`

int(hash,16) % 38 = 30
結果：🔴 紅(30)
```
