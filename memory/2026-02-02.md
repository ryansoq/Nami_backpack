# 2026-02-02 日記

## ShioKaze v4 開發 🌊

今天把 ShioKaze 礦工升級到 v4！

**v4 新功能：**
- 多進程並行挖礦（`--workers` 可調）
- 智能 nonce 分配（每個 worker 負責不同區段）
- 精確 hashrate 統計
- gRPC 自動重連機制

**技術學習：**
- Kaspa gRPC 用 `MessageStream` 不是獨立 RPC
- `pre_pow_hash` 要自己計算（blake2b 序列化整個 header）
- gRPC 會靜默斷線！需要加入重連機制
- Python multiprocessing 的 `Manager().dict()` 可跨進程共享狀態

**效能：** ~15-22 kH/s with 2 workers
