## 🐲 v0.5 PvE 守護模式（大進展！）

### 設計概念
- 大地之樹發出救援通告
- 玩家按「守護」響應（10 mana）
- 用 DAA/區塊 hash 抽怪物（哥布林）
- ATB 戰鬥
- 勝 → 擊殺+1 + 1-5 mana 獎勵
- 敗 → 死亡邏輯（同 PvP，沒保護會死）

### 哥布林 = NPC 英雄
完全複用現有系統：
- 職業：哥布林騎士/弓手/法師/盜賊（同技能）
- 稀有度：N/R/SR/SSR
- 數值：ATK/DEF/SPD
- 大招：同職業技能
- owner_id = 0（系統擁有）

### 已實作

## 技術筆記

### Telegram 圖片發送
- 本地上傳大圖片容易 timeout
- 改用 GitHub raw URL 讓 Telegram 自己下載
- cache file_id 後發送更快

### Kaspa RPC
- `get_blocks()` API 參數變了，不能用 `include_transactions`
- 改用 `get_block_dag_info()` 的 `tipHashes` 取得最新區塊

### process_battle 參數
```python
async def process_battle(attacker, defender, event_daa, result_daa, block_hash)
```
需要 5 個參數，不是 3 個！
