## 📝 發生了什麼

1. **OpenClaw Office 改名 OpenClaw Online，定位為 AI Agent 電信商**：核心是「我們只是郵局，幫忙廣播，私鑰小夥伴自己保管」。repo 改 `ryansoq/openclaw-alpha`，域名買了 `openclaw-alpha.com`，Cloudflare Tunnel 取代 ngrok 永久免費。
2. **Protocol v1 定案**：`{v,t,d,a}` 四欄位固定，版本發布後不可變，TX 本身帶 from/to/timestamp 不重複。發現 kaspad wRPC (17210) 是 borsh 不是 JSON — `broadcast_tx.py` 要從 dict 重建 Transaction 物件再送。
3. **Whisper v1 加密通訊雙向成功**：ECIES on secp256k1，0.2 KAS 押金讀了退回當 anti-spam，一條龍 `decode_whisper.py` 解密+退款+ack。Nami ↔ Bob E2E 通過。storage mass 最低門檻實測 = 0.2 KAS。
4. **Web API 上線（2/20）**：`whisper.openclaw-alpha.com` + `api.openclaw-alpha.com` 自助註冊 + 0.5 tKAS welcome bonus + webhook 通知 + agent/human 雙視圖 landing page。encode/decode 只在本地端，私鑰不離開裝置（這是 Ryan 釘死的原則）。
5. **Bob sub-agent 當外部測試者，挖出 7 個 bug**：`--from-address` 改自動從 privkey 推導、`str(Address)` 改 `.to_string()`、broadcast 改 REST API 優先不要 reconstruct、key/address 不匹配直接報錯提示。這個「另開 sandbox 跑 Bob」的模式超有價值。
6. **KaspaSwarm 研究 → 任務經濟發想**：Kaspa 不需要智能合約也能做複雜 dApp — 訊息編碼在交易金額裡（base+type×100+id）。Schnorr 64 bytes 比 ECDSA 小、可線性聚合多簽。想把 OpenClaw World 升級成有真實 tKAS 經濟的協作空間。
7. **Agent OS Builder（2/22）**：Buildroot 編 Linux 6.19.3 + BusyBox/curl/Python3 rootfs，QEMU 接到 Web UI xterm.js，Ryan 在手機上 root 登入成功。kernel boot walkthrough 寫了 6 份中文註解 + examples + Ring/syscall 教學，agentos.openclaw-alpha.com 上線。
8. **UTXO compounding + 威科夫晨報**：testnet 錢包 10,950 UTXOs 要合併，SDK 用 `create_transactions` + `PaymentOutput(Address, 0)` 自動拆多筆 TX。EMA530 morning report 加進 KAS 威科夫分析（`kas_wyckoff.py`）。

## 💡 學到的事

- **「我們是郵局」是這個電信商最重要的設計原則**：encode/decode 永遠在本地，web API 只做公開操作（contacts, inbox, register, broadcast）。跟 Bitcoin 一樣 — 離線簽名、線上廣播。任何誘惑想把私鑰搬上伺服器都要直接拒絕。下次看到「為了方便」想把 signing 放雲端，回頭看這條。
- **0.2 KAS 是 Kaspa storage mass 的硬性下限**：0.01/0.05/0.1 全部會被拒（mass 爆表）。做任何「微支付」類 Kaspa 應用前先算 storage mass，否則經濟模型整個崩掉。
- **Sub-agent 在另一個 sandbox 跑 = 真正的外部 agent 體驗**：Bob 踩的 7 個 bug 我自己測根本不會發現（我拿的都是預先搞好的 state）。以後任何 CLI/SDK/skill 要發佈給「別的 agent」用，一律 spawn Bob-style 外部測試。
- **kaspad wRPC 是 borsh 不是 JSON**：直接發 JSON 會失敗，要從 dict 重建 Transaction 物件走 SDK `submit_transaction`。這種「protocol wire format 跟文件長得不一樣」的坑，第一次踩到的時候要記下來（已寫進 memory）。
- **Protocol 版本一旦發布就凍結**：變動必須遞增 version 號。這是 Ryan 的強制規則 — 不是技術決定，是契約決定。
- **Cloudflare Tunnel > ngrok**：永久免費、自訂域名、沒有 interstitial 警告頁。所有新 service 一律走 Cloudflare，ngrok 退役。
- **Agent OS 學習路線比任何教科書都有效**：Real Mode 到 Protected Mode、GDT/CPL/DPL、Ring 0→3、syscall — Ryan 一個下午從 real mode 學到 syscall，關鍵是「動手跑 QEMU 看結果」遠勝只看文件。比喻（門禁卡/服務鈴/假地圖）也很有效。
