## 💡 學到的事

- **Godot Web export 的坑不值得踩**：headless 手寫 .tscn 的 Control layout 在 Web 環境不正確展開，而且 console 沒 error 很難 debug。同一個遊戲概念用純 HTML5 Canvas 一天就能跑，Godot 卡了兩天還黑屏。教訓：mobile web 遊戲先 HTML5，除非真的需要 Godot 的 3D/physics。
- **Safari 快取殺手 = query param 沒用**：`?v=123` 在 Chrome 會 bust cache，在 Safari 不會。要嘛真的改檔名，要嘛下 `no-cache` header（serve.cjs 這次兩個都做）。
- **多人同步的行軍結算必須有 idempotent flag**：periodic sync 從 server 拉 marches，已結算的若沒標記會被重複算 → 兵力無限累加。`settled` 標記是必須的，不能靠「不要拉已結算的」因為 client/server 時鐘不一致。
- **設計 feedback 先確認再動**：Ryan 說「本質上有線嗎？」我以為他要拿掉線，其實他只是要確認語意。重構之前先問一句比做完全錯版本好。
- **WSL agent-browser headless 有 known bug**：CDP + Python websockets 是可靠備援，兩個交叉用。（記進 TOOLS.md 了）
