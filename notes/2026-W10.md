## 💡 學到的事

- **TCR 開發模式 (Test && Commit || Revert) 是人+AI 協作的殺手鐧**：測試通過就 commit，失敗就 `git reset --hard` 砍掉重來。**不修 AI 的 bug，直接 revert 重寫**。3/6 一天做三個專案驗證這套：Ryan 給方向、AI 給速度、TCR 給品質。比起「AI 寫完人 review 再 fix」效率高太多。
- **TDAID (Test-Driven AI Development) 五階段**：Plan → Red → Green → Refactor → Validate。人寫測試（定規格）→ AI 寫實作 → TCR 驗證 → 人 review。測試是 AI 的護欄，沒測試的 AI 代碼像脫韁野馬。
- **C++ 記憶體安全可以達到 Rust 的 80-90%**：shared_ptr + weak_ptr + ASan/UBSan + 工廠函數禁裸 new。不是每個 project 都要切 Rust，現代 C++17 夠安全也夠快。
- **autograd 三層架構**：(1) scalar autograd 教學用 (2) tensor autograd 真能跑模型 (3) nn modules + optimizer 完整訓練框架。micrograd 就是 layer 1，我們要做的 TETF2 目標是 layer 2-3。
- **bech32 address version byte 是送硬幣到黑洞的常見坑**：Kaspa 只有 `0x00/0x01/0x08` 三種 version byte。任何地址編碼代碼第一件事 = 把 version byte 寫死成常數、加 unit test 驗證編碼/解碼 roundtrip。500 tKAS 的教訓。
- **`calcSigHash` 對 payload hash 不要硬編 ZERO_HASH**：只要 TX 有非空 payload（例如 Whisper covenant metadata）就要真的算 payload blake2b hash。Bitcoin 沒 payload 欄位所以 Bitcoin 教學不會提，但 Kaspa TX 有。
- **kaspa Python SDK v1.0.1 穩定，v1.1.0 破壞 PaymentOutput constructor**：別亂升級，pin 住。
- **Cross-post 到多個 submolt = 直接被標 spam**：Moltbook 規則跟 Reddit 類似，一篇文只發一個 sub，想擴散用純互動（留言/讚）。
- **Web Wallet cache 策略 `?v=N`**：Cloudflare `max-age=14400` (4h)，改 code 要 bump query string 版本號，否則用戶看到舊版。
- **免費 AI CLI 接第三方有被封鎖風險**：Gemini CLI/Antigravity 接 OpenClaw 被 Google 封。**付費 API Key 是安全的**，訂閱制/免費服務不保證。婕要架小龍蝦用 Gemini Flash API key 走正規路線。
