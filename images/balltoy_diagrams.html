🧠 BFS 搜尋演算法流程

flowchart TD
    S([開始搜尋]) --> PUSH["將起始 node 放入 Queue"]
    PUSH --> CHECK{Queue 空了?}
    
    CHECK -->|否| POP["取出 Queue 前端 node"]
    CHECK -->|是| DONE([🏆 回傳最佳解])
    
    POP --> COMBO["calculateCombo()
計算當前 combo"]
    COMBO --> SCORE["計算加權分數
= Σ(各色combo × 權重)"]
    
    SCORE --> BETTER{分數 > 目前最高?}
    BETTER -->|是| UPDATE["✨ 更新最佳解"]
    BETTER -->|否| CUT{"🔪 剪枝判斷
剩餘步數 + 分數
< 最高分?"}
    
    UPDATE --> DEPTH
    CUT -->|是| SKIP["✂️ 跳過（剪枝）"]
    CUT -->|否| DEPTH
    
    SKIP --> CHECK
    
    DEPTH{步數 < 上限?}
    DEPTH -->|否| CHECK
    DEPTH -->|是| EXPAND["展開子節點
（避免回頭路）"]
    
    EXPAND --> M1["→ moveBead(右)"]
    EXPAND --> M2["← moveBead(左)"]
    EXPAND --> M3["↓ moveBead(下)"]
    EXPAND --> M4["↑ moveBead(上)"]
    
    M1 --> CHECK
    M2 --> CHECK
    M3 --> CHECK
    M4 --> CHECK

    style S fill:#00CED1,color:#000
    style DONE fill:#FFD700,color:#000
    style UPDATE fill:#4CAF50,color:#fff
    style SKIP fill:#FF5252,color:#fff

🎯 三消判定流程 (nodeTag)

flowchart TD
    A([輸入盤面]) --> B["🏷️ Tag 階段
掃描所有格子"]
    B --> C{"水平三連?
map[i][j-1]==map[i][j]==map[i][j+1]"}
    C -->|是| D["標記為 tag+7
（原色+numberOfbeads）"]
    C -->|否| E{"垂直三連?
map[i-1][j]==map[i][j]==map[i+1][j]"}
    E -->|是| D
    E -->|否| F[保持原樣]
    
    D --> G["🎭 Mask 階段
分離消除珠 vs 保留珠"]
    F --> G
    
    G --> H["⬇️ 天降處理
上方珠子往下掉填空"]
    
    H --> I["📊 Combo 計數
Flood Fill 計算連通區域"]
    I --> J["每個連通區域 = 1 combo
記錄各色 combo 數"]
    
    J --> K([回傳結果])

    style A fill:#00CED1,color:#000

📊 資料結構

struct node {
    byte currentMap[5][6];     // 🎮 5×6 盤面（光暗水火木心 = 1-6）
    byte path[30];             // 🗺️ 移動路徑（方向: 2↓ 4← 6→ 8↑）
    byte step;                 // 👣 已走步數
    point startPos;            // 📍 起始位置
    point currentPos;          // 📍 當前位置
    byte brightCombo;          // ✨ 光 combo 數
    byte darkCombo;            // 🌑 暗 combo 數
    byte waterCombo;           // 💧 水 combo 數
    byte fireCombo;            // 🔥 火 combo 數
    byte woodCombo;            // 🌿 木 combo 數
    byte heartCombo;           // ❤️ 心 combo 數
    byte totalCombo;           // 🏆 總 combo 數
};

// Queue: std::queue<node> NDQueue  →  BFS 廣度優先搜尋
// 剪枝: artOfCut + valueOfCut     →  加速搜尋
// 路徑長度: length (預設 20 步)    →  搜尋深度上限
