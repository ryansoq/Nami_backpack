# 🌲 守護世界之樹 - 遊戲設計

## 核心玩法
- 世界之樹在中心，需要被守護
- 怪物（柱子人）從四周生成，慢慢逼近
- 只有「保護型」英雄能上場守護
- 英雄自動攔截、碰撞消滅怪物
- 怪物碰到世界樹 = 扣血

## 英雄系統
- 🛡️ **保護型**：可上場守護世界樹
- ⚔️ 其他類型：暫時不能參加（未來擴展）
- 📊 上場上限：3-5 隻

## UI 設計
```
┌─────────────────┐
│ 🌲 娜米的英雄世界 │  ← 可縮放，避免擋住
│ 🛡️ 保護英雄：3   │
│ 💚 世界樹：100% │
└─────────────────┘
```
- 標題區塊可縮小/展開
- 遊戲時自動淡化
