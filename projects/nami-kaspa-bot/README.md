# 🌲 娜米的英雄奇幻冒險

> 結合區塊鏈 + 卡片收集 + ATB 戰鬥 + PoS 獎勵的鏈遊

Telegram Bot: [@Nami_Kaspa_Bot](https://t.me/Nami_Kaspa_Bot)

---

## 🎮 遊戲簡介

這是一款基於 **Kaspa 區塊鏈** 的卡牌對戰遊戲。每張英雄卡都是獨一無二的鏈上資產，戰鬥結果由區塊 hash 公平決定，所有事件都可驗證追溯。

### ✨ 特色

- **🎲 公平抽卡**：英雄屬性由區塊 hash 決定，無法作弊
- **⚔️ ATB 戰鬥**：類似 FF 系列的即時戰鬥系統
- **💀 永久死亡**：PvP 敗者英雄永久死亡（除非受保護）
- **🔗 完整上鏈**：出生、戰鬥、死亡都有鏈上記錄
- **💰 PoS 獎勵**：持有英雄可獲得定期獎勵分潤

│                                                  │

## 🔗 鏈上機制

### 命運決定流程

```
玩家付費 10 mana
      │
      ▼
交易確認，取得 DAA (區塊高度)
      │
      ▼
找 DAA+1 後第一個官方區塊
      │
      ▼
區塊 hash = 命運來源
      │
      ▼
hash → 屬性/戰鬥結果
```

### 銘文結構

每個英雄的事件都記錄在鏈上：

```json
{
  "type": "birth",           // birth/pvp_win/death
  "daa": 381858178,          // 英雄 ID = 出生時的 DAA
  "pre_tx": null,            // 前一個銘文（鏈條追蹤）
  "payment_tx": "abc123...", // 付費交易
  "source_hash": "def456..." // 命運區塊 hash
}
```
