# 🌲 v0.5 PvE 守護模式設計

> 大地之樹的守護者們，怪物來襲！

---

## 📜 概述

當 DAA 尾數達到 **x77777** 時，大地之樹發出救援通告，玩家可以響應並與隨機生成的哥布林戰鬥。

---

## 🎮 流程

```
┌─────────────────────────────────────────────────────────┐
│  📣 大地之樹發出救援通告！                                │
│                                                         │
│  「有東西正在襲擊世界之樹！」                             │
│  「英雄們，請前來守護！」                                 │
│                                                         │
│  ⏱️ 100 秒內響應                                        │
│                                                         │
│  [🛡️ 守護 (10 mana)]     [❌ 取消]                      │
└─────────────────────────────────────────────────────────┘
           │
           ▼ 玩家按「守護」
┌─────────────────────────────────────────────────────────┐
│  1. 驗證保護英雄存在                                      │
│  2. 扣除 10 mana                                         │
│  3. 取得命運區塊（付款確認後的下一個區塊）                  │
│  4. 用 hash 生成哥布林（職業 + 稀有度 + 數值）             │
│  5. ATB 戰鬥：保護英雄 vs 哥布林                          │
│  6. 結算：                                               │
│     - 勝利 → 擊殺 +1，獲得 1-5 mana                      │
│     - 失敗 → 無懲罰（PvE 保護）                          │
└─────────────────────────────────────────────────────────┘
```

---

## 👹 哥布林系統

哥布林 = NPC 英雄，完全複用現有系統：

### 職業（同玩家）
| 職業 | 大招 |
|------|------|
| 哥布林騎士 | 衝擊之暈 |
| 哥布林法師 | 魔力風暴 |
| 哥布林弓手 | 貫穿之箭 |
| 哥布林盜賊 | 幻影步 |

### 稀有度（同機率）
| 稀有度 | 機率 | 名稱 |
|--------|------|------|
| N | 70% | 哥布林小兵 |
| R | 20% | 哥布林戰士 |
| SR | 8% | 哥布林精英 |
| SSR | 2% | 哥布林王 |

### 數值
- ATK/DEF/SPD：同玩家算法（用區塊 hash）
- 完全隨機，可能很弱也可能很強

---

## 💰 經濟

| 項目 | 數值 |
|------|------|
| 參戰費 | 10 mana |
| 勝利獎勵 | 1-5 mana（同 PvP） |
| 失敗懲罰 | 無（PvE 保護機制） |

**淨收益：** -10 + (1~5) = -9 ~ -5 mana（略虧）

⚠️ **注意：PvE 跟 PvP 完全一樣**
- 輸了 + 沒保護 → **英雄死亡**
- 輸了 + 有保護 → 英雄倖存
