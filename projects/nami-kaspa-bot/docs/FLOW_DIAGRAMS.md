## 🔌 RPC 連線管理

### 舊架構 vs 新架構

```
【舊架構】每次操作都建立新連線

func_A()                func_B()                func_C()
    │                       │                       │
    ▼                       ▼                       ▼
┌────────┐             ┌────────┐             ┌────────┐
│connect │             │connect │             │connect │
└────────┘             └────────┘             └────────┘
    │                       │                       │
    ▼                       ▼                       ▼
  操作                     操作                     操作
    │                       │                       │
    ▼                       ▼                       ▼
┌────────┐             ┌────────┐             ┌────────┐
│disconnect            │disconnect            │disconnect
└────────┘             └────────┘             └────────┘

問題：
- 連線開銷大
- 沒有重連機制
- 沒有超時處理


【新架構】統一連線管理器 (rpc_manager.py)

func_A()    func_B()    func_C()
    │           │           │
    └─────┬─────┴─────┬─────┘
          ▼           ▼
    ┌─────────────────────┐
    │    RpcManager       │
    │  (單例連線池)        │
    ├─────────────────────┤
    │ • 自動重連          │
    │ • 超時處理          │
    │ • 心跳檢測          │
    │ • 請求重試          │
    └──────────┬──────────┘
               │
               ▼
    ┌─────────────────────┐
    │   Kaspa RPC Node    │
    │   (ws://127.0.0.1)  │
    └─────────────────────┘

優點：
- 連線復用
- 自動重連
- 統一管理
```

## 💰 獎勵發放流程

### PoS 式獎勵機制

```
┌─────────────────────────────────────────────────────────────────┐
│                    定時觸發（每 24 小時）                         │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ 1️⃣ 計算獎池                                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   大地之樹餘額 🌲                                                │
│        │                                                        │
│        ▼                                                        │
│   保留金 = 餘額 × 20%                                           │
│   可分配 = 餘額 × 80%                                           │
│   本次發放 = min(可分配, 每日上限)                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ 2️⃣ 計算每位英雄權重                                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   遍歷所有存活英雄：                                            │
│                                                                  │
│   weight = base_weight                                          │
│          × rarity_multiplier    (稀有度加成)                    │
│          × (1 + kills × 0.1)    (擊殺加成)                      │
│          × survival_bonus       (存活時間加成)                  │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ 稀有度權重：                                            │   │
│   │   Common: ×1.0 | Uncommon: ×1.5 | Rare: ×2.0           │   │
│   │   Epic: ×3.0   | Legendary: ×5.0 | Mythic: ×10.0       │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ 3️⃣ 分配獎勵                                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   總權重 = Σ(各英雄權重)                                        │
│                                                                  │
│   每位英雄獎勵 = 本次發放 × (英雄權重 / 總權重)                 │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │                                                         │   │
│   │   大地之樹 🌲 ────────→ 玩家A (英雄1, 英雄2)            │   │
│   │              └──────→ 玩家B (英雄3)                    │   │
│   │              └──────→ 玩家C (英雄4, 英雄5, 英雄6)      │   │
│   │                                                         │   │
│   │   合併同玩家的多隻英雄獎勵為單筆交易                    │   │
```
