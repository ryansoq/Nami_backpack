# 🌲 娜米的英雄舞台

像素風格的英雄遊戲視覺化展示頁面

## 功能

- 🎮 像素風格英雄角色（純 CSS 繪製）
- ✨ 動態浮動動畫
- 🔥 火焰特效
- 💬 對話氣泡
- 📺 即時 Live Feed
- 🌲 大地之樹背景
- ⭐ 星空背景動畫

## 本地預覽

```bash
cd ~/nami-backpack/projects/pixel-hero-stage
python3 -m http.server 8080
```

然後打開 http://localhost:8080

## 部署

可部署到：
- Vercel
- GitHub Pages
- Netlify
